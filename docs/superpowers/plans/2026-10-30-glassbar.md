# Glassbar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir Glassbar, la barra de cristal nativa para Windows descrita en `docs/superpowers/specs/2026-10-30-glassbar-design.md`, hasta tener `Glassbar.exe` funcional y el código WPF apartado en la rama `legacy-wpf`.

**Architecture:** Un crate binario Rust. Hilo de interfaz con bucle de mensajes Win32; ventanas popup sin bitmap de redirección cuyo contenido son visuales de DirectComposition dibujados con Direct2D. Lógica de datos, layout, caché, versiones e idiomas en módulos puros con tests. Win32 solo en los módulos de borde.

**Tech Stack:** Rust 1.97 stable, crates `windows` 0.62, `serde`, `serde_json`, `winresource` (build). Windows SDK 10.0.26100 para `rc.exe`.

**Convenciones del plan**

- Todos los comandos se ejecutan desde la raíz del repositorio `F:\Custom apps\BatLauncher` en Git Bash.
- Los commits usan la identidad del repositorio: `git -c user.name="Alejandro Escarpa Prieto" -c user.email="46727850+TermiSenpai@users.noreply.github.com" commit ...`. Abreviado abajo como `gcommit`. Definir una vez por sesión: `gcommit() { git -c user.name="Alejandro Escarpa Prieto" -c user.email="46727850+TermiSenpai@users.noreply.github.com" commit "$@"; }`.
- Todo mensaje de commit termina con la línea `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Los nombres de métodos COM sobrecargados en `windows-rs` llevan sufijo numérico en orden de declaración; por ejemplo `IDCompositionVisual::SetOffsetX` recibe animación y `SetOffsetX2` recibe `f32`. Si el compilador discrepa, confiar en el compilador.
- "Verificar" significa ejecutar el comando y comprobar la salida indicada antes de seguir.

```rust
use std::path::{Path, PathBuf};
use std::{fs, io};

pub const APP_DIR_NAME: &str = "Glassbar";
pub const LEGACY_DIR_NAME: &str = "BatLauncher";

fn local_app_data() -> PathBuf {
    std::env::var_os("LOCALAPPDATA").map(PathBuf::from).unwrap_or_else(|| PathBuf::from("."))
}

pub fn data_dir() -> PathBuf {
    let d = local_app_data().join(APP_DIR_NAME);
    let _ = fs::create_dir_all(&d);
    d
}
pub fn icons_dir() -> PathBuf { let d = data_dir().join("icons"); let _ = fs::create_dir_all(&d); d }
pub fn update_dir() -> PathBuf { let d = data_dir().join("update"); let _ = fs::create_dir_all(&d); d }
pub fn entries_path() -> PathBuf { data_dir().join("entries.json") }
pub fn settings_path() -> PathBuf { data_dir().join("settings.json") }
pub fn cache_path() -> PathBuf { data_dir().join("icons.cache") }
pub fn log_path() -> PathBuf { data_dir().join("log.txt") }
pub fn legacy_dir() -> PathBuf { local_app_data().join(LEGACY_DIR_NAME) }

pub fn write_atomic(path: &Path, bytes: &[u8]) -> io::Result<()> {
    let tmp = path.with_extension(format!("{}.tmp", path.extension().and_then(|e| e.to_str()).unwrap_or("")));
    fs::write(&tmp, bytes)?;
    match fs::rename(&tmp, path) {
        Ok(()) => Ok(()),
        Err(_) => { fs::remove_file(path).ok(); fs::rename(&tmp, path) }
    }
}

pub fn timestamp_now() -> String {
    // Fecha y hora local sin crates: usar GetLocalTime de Win32.
    use windows::Win32::System::SystemInformation::GetLocalTime;
    let t = unsafe { GetLocalTime() };
    format!("{:04}{:02}{:02}-{:02}{:02}{:02}", t.wYear, t.wMonth, t.wDay, t.wHour, t.wMinute, t.wSecond)
}

pub fn quarantine_corrupt(path: &Path) -> io::Result<PathBuf> {
    let name = path.file_name().and_then(|n| n.to_str()).unwrap_or("file");
    let dest = path.with_file_name(format!("{name}.corrupt-{}", timestamp_now()));
    fs::rename(path, &dest)?;
    Ok(dest)
}
```

Nota: `write_atomic` usa `rename` sobre el destino; en Windows `fs::rename` reemplaza archivos existentes desde Rust 1.x con `MoveFileEx(REPLACE_EXISTING)`. El `Err` de respaldo cubre destinos bloqueados.

- [ ] **Step 2: Implementación**

```rust
use std::io::Write;
use std::path::{Path, PathBuf};
use std::sync::Mutex;

pub const MAX_BYTES: usize = 1024 * 1024;
static FILE: Mutex<Option<PathBuf>> = Mutex::new(None);

pub fn init() {
    let p = crate::fsx::log_path();
    rotate_if_needed(&p);
    *FILE.lock().unwrap() = Some(p);
    std::panic::set_hook(Box::new(|info| {
        let msg = match info.payload().downcast_ref::<&str>() {
            Some(s) => s.to_string(),
            None => info.payload().downcast_ref::<String>().cloned().unwrap_or_default(),
        };
        let loc = info.location().map(|l| format!("{}:{}", l.file(), l.line())).unwrap_or_default();
        write("PANIC", &format!("{msg} at {loc}"));
        crate::ui::window::destroy_all_windows();
    }));
}

pub fn rotate_if_needed(p: &Path) {
    if let Ok(m) = std::fs::metadata(p) {
        if m.len() as usize > MAX_BYTES {
            let rotated = p.with_file_name("log.1.txt");
            let _ = std::fs::remove_file(&rotated);
            let _ = std::fs::rename(p, rotated);
        }
    }
}
```

```rust
use std::collections::HashMap;
use std::sync::{OnceLock, RwLock};

pub const ES: &str = include_str!("../assets/strings/es.json");
pub const EN: &str = include_str!("../assets/strings/en.json");

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Lang { Es, En }

impl Lang {
    pub fn from_primary_lang_id(primary: u16) -> Lang { if primary == 0x0A { Lang::Es } else { Lang::En } }
    pub fn system() -> Lang {
        use windows::Win32::Globalization::GetUserDefaultUILanguage; // feature Win32_Globalization
        let id = unsafe { GetUserDefaultUILanguage() };
        Lang::from_primary_lang_id(id & 0x3FF)
    }
}

static TABLES: OnceLock<HashMap<Lang, HashMap<String, String>>> = OnceLock::new();
static CURRENT: RwLock<Lang> = RwLock::new(Lang::En);

fn tables() -> &'static HashMap<Lang, HashMap<String, String>> {
    TABLES.get_or_init(|| {
        let parse = |s: &str| serde_json::from_str::<HashMap<String, String>>(s).expect("strings json");
        HashMap::from([(Lang::Es, parse(ES)), (Lang::En, parse(EN))])
    })
}

pub fn set_lang(l: Lang) { *CURRENT.write().unwrap() = l; }
pub fn lang() -> Lang { *CURRENT.read().unwrap() }

pub fn t(key: &str) -> &'static str {
    let l = lang();
    match tables().get(&l).and_then(|m| m.get(key)) {
        Some(s) => s.as_str(),
        None => Box::leak(key.to_string().into_boxed_str()),
    }
}

pub fn tf(key: &str, args: &[&str]) -> String {
    let mut s = t(key).to_string();
    for (i, a) in args.iter().enumerate() { s = s.replace(&format!("{{{i}}}"), a); }
    s
}
```

DirectComposition anima con segmentos polinómicos `AddCubic(begin, c, l, q, cu)` sobre `t` en segundos desde `begin`. Para un valor de `a` a `b` en `d` segundos:

```rust
#[derive(Clone, Copy, PartialEq, Debug)]
pub enum Ease { OutCubic, InCubic, Linear }

/// Coeficientes (constante, lineal, cuadrático, cúbico) del polinomio en t∈[0,d] que lleva de a hasta b.
pub fn coeffs(ease: Ease, a: f32, b: f32, d: f32) -> (f32, f32, f32, f32) {
    let r = b - a;
    match ease {
        Ease::Linear   => (a, r / d, 0.0, 0.0),
        // s = t/d; v = a + r*(1 - (1-s)^3) = a + r*(3s - 3s^2 + s^3)
        Ease::OutCubic => (a, 3.0 * r / d, -3.0 * r / (d * d), r / (d * d * d)),
        // v = a + r*s^3
        Ease::InCubic  => (a, 0.0, 0.0, r / (d * d * d)),
    }
}
pub fn eval(c: (f32, f32, f32, f32), t: f32) -> f32 { c.0 + c.1 * t + c.2 * t * t + c.3 * t * t * t }
```

```rust
pub struct AnimSpec { pub from: f32, pub to: f32, pub duration_ms: u32, pub delay_ms: u32, pub ease: Ease }

pub fn build(dcomp: &IDCompositionDesktopDevice, s: &AnimSpec) -> windows::core::Result<IDCompositionAnimation> {
    let a = unsafe { dcomp.CreateAnimation()? };
    let delay = s.delay_ms as f64 / 1000.0; let d = s.duration_ms as f32 / 1000.0;
    if s.delay_ms > 0 { unsafe { a.AddCubic(0.0, s.from, 0.0, 0.0, 0.0)?; } }
    let (c, l, q, cu) = coeffs(s.ease, s.from, s.to, d);
    unsafe { a.AddCubic(delay, c, l, q, cu)?; a.End(delay + d as f64, s.to)?; }
    Ok(a)
}
```

## Notas transversales (aplican a varias tareas)

- **Nombres de `gfx::anim`.** Además de `apply_opacity`, el módulo expone `apply_offset_x`, `apply_offset_y` y `apply_scale`, todos con la firma `(dcomp, visual, spec: &AnimSpec, animate: bool)`. Task 20 y Task 21 usan esos nombres.
- **Dispositivo gráfico perdido.** Toda llamada de dibujo devuelve `windows::core::Result`. En `Toolbar`, un error con `Gfx::is_device_lost(hr)` provoca `gfx = Gfx::create()` y `rebuild()`; si vuelve a fallar en la misma apertura, `log_error!` y `post_quit()`. Lo mismo en `Dialog::repaint`.
- **Archivo no encontrado.** `Toolbar::on_click(Hit::Cell(i))` comprueba `entries[i].path.exists()` en el momento del clic; si no existe, no lanza y marca la celda como `missing` repintándola. Si `launch` devuelve `Err(msg)`, la barra no se oculta y muestra 2,5 s un tooltip con `tf("bar.launch_error", &[&msg])` sobre la celda, usando `Tooltip` y `set_timer(TIMER_TOAST, 2500)`.
- **Carpeta `update\`.** `app::run` vacía `fsx::update_dir()` al arrancar, antes de cualquier comprobación.
- **Ruta del exe movida.** `app::run` llama a `lifecycle.refresh_startup_path(&settings)` tras crear `Lifecycle` cuando `resident && start_with_windows`.
- **Cambios de tema del sistema.** La ventana de mensajes recibe `WM_SETTINGCHANGE` (lParam `"ImmersiveColorSet"`) y `WM_DWMCOLORIZATIONCOLORCHANGED`; recalcula `palette(settings.theme)` y envía `WM_THEME_CHANGED` a la barra y a los diálogos abiertos.
- **Timers.** Ids: `TIMER_TOOLTIP = 1`, `TIMER_CARET = 2`, `TIMER_HIDE = 3`, `TIMER_TOAST = 4`, `TIMER_UPDATE_CHECK = 5`. Todos se matan en cuanto cumplen su función.
- **Contador de ventanas.** `app` mantiene `open_windows`; `Dialog::create` lo incrementa y `WM_DESTROY` del diálogo lo decrementa y llama a `app::maybe_exit()`.
- **Test de foco de `Form`** (Task 22), código concreto:
